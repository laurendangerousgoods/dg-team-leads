# DG XXL 2027 team lead dashboards

One page per city: /sydney/ /brisbane/ /perth/ /adelaide/ /melbourne/.
Melbourne has tabs for the whole city, Team 1, Team 2, Team 3 and Hosts (links: /melbourne/#team-1, #team-2, #team-3, #hosts).
Sales are read live from the promoter leaderboards (laurendangerousgoods.github.io/dg-promoters/<city>/),
so they update whenever the leaderboards do. Promoter contact details are encrypted in each page and
need the city's team lead passcode to open.
